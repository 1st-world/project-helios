Explore project

For the next response, the model may list, search and read allowed UTF-8 file ranges in this workspace, beyond the basic project overview. Selected content is sent to your model provider. Files stay unchanged and commands are unavailable.

Automatic exploration excludes hidden/system paths, case-sensitive .gitignore matches, links and Helios runtime data. Explicit attachments use their own selection and processing rules.

Exploration can make repeated paid model calls and reuse growing tool results. Stop ends further work; calls already made can still incur cost. No exploration goal is set by default.

Optional goals

Goals are checked between work steps. Time and cost goals do not interrupt an in-flight call or impose a billing cap. A completed answer can exceed a target. Incomplete cost records stop further calls when a cost goal is set. Memory-summary calls follow your separate memory settings and are excluded from these exploration goals.
