# 공유 Provider 통신 기록

Helios가 Provider에 보낸 요청, 받은 응답, 보고된 사용량을 정리한 자료입니다. 검증에는 합성 입력을 사용했습니다. 이전에 저장한 대화에서 얻은 관찰은 별도로 표시합니다.

- [기록 목록](results.json)에서 실행과 관찰 기록을 찾을 수 있습니다.
- [메모리 후속 검증 M01](runs/2026-11-09/M01-01.json)에는 DeepSeek V4.1 Flash의 요약과 확인 답변이 있습니다.
- [10월 31일 호출 집계](runs/2026-10-31/summary.json)와 [이전 통신 기록](history/api-validation-results.json)에서 과거 근거를 확인할 수 있습니다.

## 기록 읽기

- `exchanges`에는 공개용 HTTP 본문과 스트림 이벤트가, `calls`에는 앱 호출 원장이 들어 있습니다. `result`에서 관찰 결과와 한계를 확인할 수 있습니다.
- 공개 식별자로 관련 항목을 연결합니다. 요청 해시는 원래 요청 본문을 기준으로 합니다.
- 경로의 날짜는 한국 표준시, 공개 타임스탬프는 UTC 기준입니다.
- `null`은 사용량 미확인, `0`은 보고된 0을 뜻합니다. 추론·캐시 토큰은 해당 사용량 합계에 포함됩니다. 비용은 저장 단가를 기준으로 추정하며 실제 호출은 한 번씩 집계합니다.

공유 기록에는 공개 추론 요약 등 관찰을 재현하는 데 필요한 내용을 담습니다. 자격 증명, 비공개 추론, 원본 저장 파일은 공개 범위에서 제외합니다.
